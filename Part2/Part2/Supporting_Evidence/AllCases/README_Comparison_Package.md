# IT305 comparison-only package: all 3 cases

This ZIP contains only artefacts comparing **Case 1 vs Case 2 vs Case 2 Enhanced together**. It deliberately omits standalone case graphs/results and does not contain Case 1-vs-Case 2 or Case 2-vs-Enhanced pairwise-only files.

Files are under `Results/`: `All_Three_Cases_Comparison.csv`, `All_Three_Cases_Summary.csv`, three all-case line graphs (throughput, elapsed time, retries), a payload-overhead availability CSV, and comparison analysis.
